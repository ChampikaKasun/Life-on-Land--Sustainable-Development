# 🌍 Life on Land — Sustainable Development Website

A multi-page responsive website built to raise awareness of the UN
Sustainable Development Goal 15: **Life on Land**. Created as a group
university project for the Web Design & Development module.

## Overview
The site presents information on land conservation, biodiversity, and
climate change across several themed pages, with a shared responsive
navigation bar and footer throughout.

## Pages
- **Splash Screen** — animated intro with a video background and auto-redirect
- **Home** — mission statement and topic cards (forest conservation, biodiversity, land degradation, climate change)
- **Volunteer** — volunteering information
- **Comparison Table** — regional land-impact data with tooltips and status indicators
- **User Profile** — sample user profile with skills, goals, and a contact form
- **Feedback** — feedback form with star rating and JavaScript validation
- **Sitemap** — interactive SVG site map
- **Team** — team members with hover-reveal details

## Tech Stack
HTML5 · CSS3 · JavaScript · Boxicons / Font Awesome

## Features
- Responsive navigation with animated hover effects
- Interactive star-rating feedback form with client-side validation
- Data comparison table with tooltips and visual status icons
- Hover-based team member cards
- SVG-based sitemap

## How to View
Open `Splash page.html` (or `Home.html`) in any modern web browser.
